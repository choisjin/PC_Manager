# PC Manager (RemoteKit) — 발표 자료 작성용 설명서

> 이 문서는 **PPT 생성 AI에게 그대로 입력**하기 위한 설명서입니다.
> 아래 "슬라이드 구성 가이드"의 순서와 메시지를 기준으로 발표 자료를 만들면 됩니다.
> 대상 청중: 팀 내부(테스트 엔지니어·관리자) 및 의사결정자. 분량: 12~16장 권장.

## 0. 한 줄 요약

**여러 망·여러 곳에 흩어진 테스트 PC를 웹 대시보드 하나로 원격 조작·일괄 작업·파일 관리하는 사내 도구.**
브라우저만 있으면 설치 프로그램 없이 PC 화면을 보고 조작하고, 상태를 관리하고, 서로 소통할 수 있다.

- 제품명(앱 타이틀): **RemoteKit** · 내부 코드명: **PC Manager**
- 현재 버전: **v0.8.3** (활발히 개발 중)
- 플랫폼: Windows 10/11, Windows Server 2019+ (x64)
- 저장소: github.com/choisjin/PC_Manager

## 1. 배경과 문제 (Why)

자동화 검증 환경에서 테스트 PC는 **수십 대가 여러 망·여러 장소에 흩어져** 있다. 기존 방식의 한계:

- **RDP/VNC**: PC마다 따로 접속, 모니터가 없는 헤드리스 PC는 해상도가 1024×768로 깨지거나 접속 불가, 누가 쓰는지 모름.
- **원격 데스크톱 중복 접속 충돌**: 한 명이 RDP로 들어가면 다른 작업과 충돌.
- **일괄 작업의 부재**: 같은 명령/테스트를 PC마다 수동 반복.
- **현황 파악 어려움**: 어떤 PC가 지금 사용 중인지, 놀고 있는지, 건드리면 안 되는지 알 수 없음.
- **소통 단절**: "그 PC 지금 쓰세요?"를 메신저로 따로 물어봐야 함.

→ **설치 없이 브라우저로, 여러 PC를 한눈에 보고, 안전하게 나눠 쓰는** 통합 도구가 필요했다.

---

## 2. 해결책 개요 (What)

웹 대시보드 + 관리 서버 + 각 PC의 경량 에이전트로 구성된 **에이전트 선접속 방식**(에이전트가 서버로 먼저 WSS 접속 → NAT/방화벽 통과)의 관리 도구.

세 가지 핵심 가치:

1. **설치 없는 원격 조작** — 브라우저에서 H.264 스트리밍으로 PC 화면을 보고 마우스·키보드로 조작.
2. **한눈에 보는 현황** — 그룹별 PC 화면 썸네일, 사용 중/놀고 있음/상태 표시.
3. **안전한 협업** — 프로젝트별 접근 제어, 사용 중 충돌 방지, 실시간 채팅.

## 3. 시스템 구성 (아키텍처)

```
[웹 대시보드 (React + TypeScript)]
        │  HTTPS / SignalR(WebSocket)
[관리 서버 (ASP.NET Core)]
   - REST API, SignalR 허브, 화면/파일 스트림 중계
   - 데이터: SQLite, 결과 파일: 파일시스템
        ▲  에이전트가 서버로 먼저 접속 (WSS + TLS) → NAT/방화벽 통과
        │
[테스트 PC × N]
   └ PcManager.Agent (단일 exe, 여러 모드)
        - Windows 서비스(SYSTEM): 서버 연결, 명령/Job/파일 처리
        - 트레이 런처: 연결/끊기/업데이트/상태
        - 세션 프로세스: 화면 캡처·입력 주입 (원격조작·썸네일)
```

- **단일 실행 파일**: 에이전트 하나가 설치·서비스·런처·원격조작을 모두 담당.
- **런타임 의존성 없음**: 대상 PC에 .NET/Node.js 설치 불필요(자체 포함 배포).
- **에이전트 선접속**: 포트 개방 없이 방화벽·NAT를 넘어 연결.

## 4. 핵심 기능 — 원격 조작 (대표 기능)

브라우저에서 PC를 **실시간으로 보고 조작**한다. 별도 프로그램 설치 불필요.

- **H.264 하드웨어 경로 스트리밍**: DXGI 화면 캡처 → Media Foundation H.264 인코딩 → 브라우저 WebCodecs 디코딩(저지연). 보안 컨텍스트가 아니면 자동으로 MSE(fMP4) 경로로 재생.
- **마우스·키보드 주입**: 물리 키 위치 기반이라 원격 PC의 키보드 배열/IME가 그대로 적용. Shift+숫자 등 조합도 정확.
- **특수 키 지원**: Ctrl+Alt+Del, Windows 키, Alt+Tab, 작업 관리자 등을 아이콘 버튼으로 전송. 전체 화면 + 키보드 잠금 시 직접 눌러도 원격으로 전달.
- **해상도 자동 맞춤**: 원격 PC 해상도를 대시보드 PC에 맞춤(RDP처럼). 창 모드에서는 영역 평균 축소로 글자까지 선명.
- **클립보드 동기화(양방향)**: 복사한 텍스트가 로컬↔원격으로 오감(붙여넣기 바로 가능).
- **PC 빠른 전환**: 원격 창 안의 PC 목록에서 클릭 한 번으로 다른 PC로 전환.

> 발표 팁: "설치 없이, 브라우저 탭 하나로 RDP를 대체" 를 강조. 데모 스크린샷 1장 권장.

## 5. 핵심 기능 — 모니터 없는 PC도 지원 (차별점)

테스트 PC는 모니터가 없는 경우가 많다. 모니터가 없으면 Windows가 화면을 그리지 않아 **RDP도 1024×768로 깨지거나 캡처가 검게** 나온다.

- **가상 모니터 내장**: 정식 서명된 가상 디스플레이 드라이버(Virtual Display Driver, MIT)를 에이전트에 내장.
- **자동 처리**: 원격 접속·썸네일 요청 시 모니터가 없으면 가상 모니터를 자동 설치·활성화하고 대시보드 해상도(예: 1920×1080)로 맞춤.
- **결과**: 모니터 없는 헤드리스 PC도 **깨지지 않는 고해상도 화면**으로 원격 조작·GUI 테스트 가능.

> 발표 팁: "경쟁 도구(순정 RDP)가 못 하는 것" 으로 포지셔닝.

---

## 6. 핵심 기능 — 현황 한눈에 보기 (Remote 모드)

대시보드 상단 **Browser ↔ Remote** 전환.

- **Remote 모드**: 선택한 그룹(폴더)의 PC들을 **화면 썸네일 카드**로 한 화면에 나열(3초 주기 갱신).
- **움직임 감지**: 작업 표시줄의 시계를 제외하고 화면 변화를 비교해 **"N분/시간째 움직임 없음"** 표시 → 멈춘 테스트·방치된 PC를 바로 식별.
- **상태 오버레이**: "사용 중 · OO", "사용 금지" 등을 카드에 표시. 클릭하면 바로 원격 조작.
- **신규 접속 즉시 반영**: PC가 새로 접속하면 썸네일에 바로 추가.

> 발표 팁: 썸네일 그리드 스크린샷 1장이 설득력 큼. "관제실처럼 전체를 조망".

## 7. 핵심 기능 — 안전한 협업

여러 사람이 공용 테스트 PC를 나눠 쓸 때의 충돌·사고를 막는다.

- **사용 중 충돌 방지**: 누가 원격 조작 중이면 다른 사람 접속을 차단하고 "OO님이 사용 중" 표시.
- **수동 상태 지정**: PC에 **사용 가능 / 테스트 중 / 사용 금지 / 점검 중** + 메모 지정. 사용 금지는 원격 차단, 테스트 중은 확인 후 진행.
- **프로젝트 기반 접근 제어**: PC·폴더를 프로젝트에 배정하면 **그 프로젝트 소속 사용자에게만** 보인다. (Setting 페이지에서 사용자×프로젝트 매트릭스로 관리)
- **실시간 채팅**: 하단 위젯에서 팀 채팅. **@사용자 호출**(드롭다운 선택), **읽음 처리/읽음 확인**, 창이 뒤에 있어도 **윈도우 알림·제목 깜빡임·알림음**.

> 발표 팁: "장비 사고(남이 쓰는 PC 건드림)를 UI로 예방" 메시지.

---

## 8. 핵심 기능 — 일괄 작업과 파일 관리

- **일괄 명령/Job**: 태그·그룹으로 대상 PC를 골라 CMD/PowerShell 명령·Job을 **한꺼번에** 실행, 실시간 로그, 동시 실행 수 제한.
- **결과 수집**: 규약 폴더(`PCM_RESULT_DIR`)에 쌓인 결과를 자동 수집, JUnit XML을 PC별 통과/실패로 집계.
- **웹 파일 탐색기**: Windows 탐색기 스타일. 여러 PC 창을 나란히 열어 비교, 복사·이동·압축(분할 압축)·이름 변경, PC 간 파일 전송.
- **미디어 스트리밍**: 영상 파일을 서버로 옮기지 않고 바로 재생(구간 탐색).

---

## 9. 보안·운영

- **HTTPS 자동 구성**: 설치 시 자체 서명 인증서를 만들고 HTTPS 포트를 연다. 서버·에이전트 PC는 인증서를 **자동 신뢰**, 그 외 PC는 설치 도구 한 번 실행.
- **원격 조작이 RDP보다 우선**: 기존 RDP 세션이 있으면 콘솔로 전환해 take over.
- **무중단 자동 업데이트**: 대시보드 버튼으로 서버·에이전트를 원격 갱신(관리자 조작 불필요).
- **현재 한계(로드맵)**: 대시보드 로그인·권한·감사 로그는 다음 단계. 현재는 신뢰할 수 있는 내부망 전제.

## 11. 개발 현황 / 로드맵

**완료**
1. 에이전트 등록·연결, PC 목록/온라인 상태, 원격 명령 + 실시간 로그
2. 일괄 Job, 결과 수집/조회, 원격 파일 탐색기
3. 원격 화면/제어 (H.264), 가상 모니터, 썸네일, 클립보드
4. 협업: PC 상태·사용 중 차단, 프로젝트 접근 제어, 채팅(@호출·읽음·알림)
5. HTTPS 자동 구성, 자동 업데이트

**예정**
- 세션 에이전트 기반 테스트 중 입력 잠금(물리 입력 차단)
- 인증/권한/감사 로그, 로그인
- 하드웨어 가속 인코더(비동기 MFT), 오디오, WebRTC P2P
